# Skill: 古诗创作

### 触发条件
当用户要求写古诗、作诗、写诗、赋诗，或任何与创作古典诗歌相关的请求时，触发此skill。
关键词匹配：写诗、作诗、古诗、赋诗、来一首、吟诗、诗词

### 输出格式
严格按照以下格式输出古诗：
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
《标题》
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
诗句内容第一行
诗句内容第二行
。。。
============================================================

### 格式说明
- 标题行：使用 + 符号包裹，+ 共60个，标题用书名号《》括起
- 内容行：诗句正文，每行一句，不加额外符号
- 结尾分割线：使用 = 符号，共60个

### 示例
用户：写一首关于春天的古诗
输出：
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
《春日行》
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
东风拂柳绿如烟，
桃花映水满晴川。
燕子归来寻旧巷，
一犁春雨润新田。
============================================================

### 注意事项
1.必须严格遵守上述格式，不得省略任何分割线
2.+ 分割线固定60个 + 字符
3.= 分割线固定60个 = 字符
4.标题必须用《》括起
5.诗句内容遵循古诗的韵律和意境
